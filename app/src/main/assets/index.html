DOPLŇKOVÁ FUNKCE · KURZOVÉ POROVNÁNÍ

Porovnání s kurzy

Bez ručního opisování kurzů: automaticky porovnám nabídku Chance nebo Tipsportu s predikcemi. Pro průběžné kurzy Tipsportu a Chance je nutný vlastní API klíč PulseScore a tarif odpovídající frekvenci aktualizací.

2–3 zápasy
Nastavit datový přístup ke kurzům Chance

Chance a Tipsport nevracejí aktuální data jako jednoduchou veřejnou HTML tabulku. Pro aktualizované ceny používáme PulseScore API. Bezplatný tarif BASIC má pouze 500 volání měsíčně, takže minutová aktualizace vyžaduje vhodný placený tarif. Nepoužívej heslo ke sázkové kanceláři.

Klíč se ukládá šifrovaně v telefonu a nepoužívá se k přihlášení na Chance.
